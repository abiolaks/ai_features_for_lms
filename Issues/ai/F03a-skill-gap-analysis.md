# F03a: Skill-Gap Analysis

- **Type:** AFK
- **Phase:** 2
- **Depends on:** AI03 (LLM Gateway), LMS `/api/v1/learner/profile`, `/api/v1/catalog`, `/api/v1/progress/user`

## What to build

Compare a learner's current skills against what their target role or track requires. Identify gaps and recommend courses + estimated effort to close them.

**Endpoint:**

`GET /mentor/skill-gap?learner_id={id}&org_id={org}`

**Behavior:**
1. Fetch learner profile from LMS (skills, goals, level)
2. Fetch course catalogue → extract skill requirements per course/track
3. Map learner skills against track requirements
4. Build prompt for gap analysis + recommendations:
   ```
   Learner skills: {skills}, goal: {goals}, level: {level}
   Track requirements: [{ track, required_skills, proficiency }]
   Catalogue courses matching gaps: [{ title, difficulty, estimated_hours }]
   
   Return JSON: { gaps: [{ skill, current_level, required_level,
   courses_available, estimated_hours }], summary }
   ```
5. Call AI03 Gateway (standard tier)
6. Return gaps with actionable recommendations

## Response shape

```json
{
  "learner_skills": ["python", "sql"],
  "gaps": [
    {
      "skill": "spark",
      "current_level": "none",
      "required_level": "intermediate",
      "courses_available": 3,
      "estimated_hours": 40
    }
  ],
  "summary": "Strong in Python and SQL. Biggest gap is distributed computing. 3 courses available."
}
```

## Acceptance criteria

- [ ] Compares learner skills against catalogue skill requirements
- [ ] Each gap includes available courses and estimated hours
- [ ] Summary is human-readable, generated by AI03
- [ ] No skill data → returns message suggesting learner add skills to profile
- [ ] Degrades gracefully when LMS data is unavailable
- [ ] Unit tests: gap calculation, course matching, empty-state handling
- [ ] Observability: span for data fetch, gateway call, gap computation
