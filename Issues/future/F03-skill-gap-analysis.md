# Future: F03 — Skill-Gap Analysis & Session Insights

- **Phase:** 2
- **Requirements covered:** AI-11 (Session Insights & Skill-Gap Analysis)
- **Depends on:** AI05 (Learner Profile), P07 (Enrollment & Progress), P08 (Quiz Engine)

## What to build

Two related features that help mentors structure productive sessions with learners:

### 1. Skill-Gap Analysis

Compare a learner's current profile against the organization's skill framework. Identify gaps and recommend focus areas.

**Endpoint:** `POST /mentor/skill-gap?learner_id={id}&org_id={org}`

```
→ {
    learner_skills: ["python", "sql"],
    org_framework: {
      "data-engineering": {
        required_skills: ["python", "sql", "spark", "airflow"],
        proficiency_level: "intermediate"
      }
    },
    gaps: [
      {
        skill: "spark",
        current_level: "none",
        required_level: "intermediate",
        courses_available: 3,
        estimated_hours: 40
      }
    ],
    summary: "Strong foundation in Python and SQL. Biggest gap is distributed computing (Spark, Airflow). 3 available courses can close this gap."
  }
```

### 2. Session Insights

Given a mentor-mentee pair, generate a structured session agenda based on the learner's recent activity and skill gaps.

**Endpoint:** `POST /mentor/session-prep?learner_id={id}&mentor_id={id}`

```
→ {
    recent_activity: {
      completed_lessons: 12,
      quiz_scores: { avg: 72, lowest_topic: "recursion" },
      stalled_modules: ["advanced-algorithms"]
    },
    suggested_agenda: [
      { topic: "Recursion review", reason: "Lowest quiz score (45%)", duration_min: 15 },
      { topic: "Algorithm complexity", reason: "Blocks progress in Advanced Algorithms", duration_min: 20 },
      { topic: "Next steps", reason: "Discuss Data Engineering track options", duration_min: 10 }
    ],
    prep_materials: [
      { lesson_title: "Recursion Basics", link: "/courses/cs101/lessons/recursion" }
    ]
  }
```

Both features call Slice 3 (tier=standard) for summary generation.

## Acceptance criteria

- [ ] Skill-gap: returns gaps between learner skills and org framework
- [ ] Skill-gap: each gap includes available courses and estimated hours
- [ ] Skill-gap: summary is human-readable, generated by LLM
- [ ] Session insights: returns recent activity summary (lessons, quizzes, stalled modules)
- [ ] Session insights: suggested agenda is prioritized by urgency (low scores first)
- [ ] Session insights: prep materials link to specific lessons
- [ ] No learner activity → returns skeleton agenda (review profile, set goals)
- [ ] Org has no skill framework → returns message suggesting admin configures one
- [ ] Unit tests: gap calculation, agenda prioritization, empty-state handling
