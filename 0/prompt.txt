# Entire CLI

## Quick reference

```bash
entire status             # Is Entire enabled? Which agents?
entire activity           # Your activity overview
entire session list       # List recent sessions
entire checkpoint list    # List recent checkpoints
entire recap              # Summarize recent checkpoint activity
entire dispatch           # Generate a dispatch summarizing recent agent work
entire doctor             # Diagnose session issues
```

## Common workflows

### Check what's happening
```bash
entire status && entire activity
```

### See what an agent did recently
```bash
entire session list && entire recap
```

### Generate a summary of agent work for sharing
```bash
entire dispatch
```

### Diagnose problems
```bash
entire doctor
```

### Inspect a specific checkpoint
```bash
entire checkpoint show <id>
entire checkpoint search "<query>"
```

## Setup (first time per repo)
```bash
entire enable
entire agent add pi
```
